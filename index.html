What the project covers

Built to review patterns without making accusations.

Repeated contact

Tracks repeated interactions between accounts and highlights when communication volume becomes unusually persistent.

Frequency changes

Compares message counts across time to detect escalation or increased engagement over a review period.

Unanswered attempts

Identifies records marked as unanswered or not replied and groups them into a visible indicator summary.

Platform diversity

Reviews whether similar activity is being spread across different communication channels, which may signal broader persistence.

Human review

The application presents findings as behavioural indicators, and leaves final interpretation to a human user.

CSV-driven workflow

Upload a CSV file, validate it locally, and replace the active dataset without storing private messages beyond the local environment.

Run it locally

Start the project on your machine.

py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python app.py

Open http://127.0.0.1:5000 in your browser to view the dashboard. The app is intended for local demonstration and should not be exposed publicly.
